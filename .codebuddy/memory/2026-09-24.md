## GHCR 构建脚本 tag 约定（重要，避免非法引用）
- 镜像名必须放路径段：`IMAGE_REPO: ${{ github.repository }}/debian`，不能在镜像名里写冒号（如 `debian:13-rust` 会导致 `debian:13-rust:main` 双冒号非法引用）。
- 变体用 metadata-action 的 `prefix=` 表达：`type=ref,event=branch,prefix=13-rust-` 等，生成 `ghcr.io/<repo>/debian:13-rust-main`。
- 各语言 workflow：`build-debian13-py13-uv-builder.yml`(prefix 13-py313-uv-)、`build-debian13-rust-builder.yml`(prefix 13-rust-)、`build-all.yml`(prefix 13-all-)。
- **tag 命名约定（统一，3 个 workflow 均已去掉 `-main` 后缀）**：改用 `type=raw,value=<变体>,enable={{is_default_branch}}` 在 main 分支打干净标签（`13-py313-uv` / `13-rust` / `13-all`），并 `type=ref,event=branch,enable=false` 关闭分支名后缀；`flavor.latest=false` 避免裸 `:latest`。发版/sha 标签保留 `prefix=<变体>-`：`type=ref,event=tag`（原始 tag 名）、`type=semver` 三档、`type=sha`。涉及文件：`build-debian13-py13-uv-builder.yml`、`build-debian13-rust-builder.yml`、`build-debian13-all.yml`。

## Dockerfile 验证步骤踩坑
- `sys.stdout.encoding` 返回大写 `'UTF-8'`，断言 `== 'utf-8'` 必败；用 `.lower()` 比较。
- 验证 RUN 不要链式 `&&` 挂 `rustup show` 或 `locale -a | grep`：任一非 0 会整条失败且无具体报错。拆成「关键校验(二进制 version)」+「信息性校验(非阻断，`|| echo WARN`)」。
- `locale -a` 在部分 glibc 输出 `C.utf8`（无连字符），grep 用 `C\.UTF-?8` 兼容匹配。
